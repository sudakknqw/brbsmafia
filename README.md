## Зачем

Когда у одного 21:00, у другого уже полночь, а третий ещё на работе, фраза «давайте вечером» не работает. Раньше это решали долгой перепиской в чате: кто когда может, во что играем, кто вообще придёт.

**brbs mafia** решает это иначе. Каждый отмечает свободное время на шкале дня по своим часам. Приложение само пересчитывает время для всех, находит общее окно и показывает, во что компания хочет играть. За час до игры бот напоминает каждому лично.

## Возможности

### Время
- **Шкала дня.** Свободные часы отмечаются прямо на ней: нажал на начало, нажал на конец, сразу видно, сколько выходит. Чужие полосы рядом, общее окно подсвечено.
- **Своё время у каждого.** Всё хранится в UTC и показывается по часам того, кто смотрит. Наведи на ник, и увидишь, сколько сейчас у друга и насколько он впереди или позади.
- **Игровой день с 08:00 до 08:00.** Ночная игра не разрывается на два дня.
- **NO.** Одна кнопка на случай, когда сегодня точно не выйдет.
- **Неделя с понедельника по воскресенье.** Плитки дней с отметками всех, «сегодня» само переезжает в 08:00. День раскрывается из плитки поверх главной, между соседними днями можно листать.

### Игры
- **Общая библиотека.** Обложки, арты и логотипы берутся из Steam автоматически. Поиск по названию, номеру или ссылке на страницу в магазине, в том числе для игр, скрытых в российском регионе.
- **Свои картинки** для игр не из Steam: обложка, баннер, шапка и логотип в тех же размерах, что у Steam.
- **Статус «хочу сейчас».** До трёх игр, живёт сутки и виден всем в ряду статусов.
- **Игры на день.** К своему времени можно приложить до пяти игр. Самая выбранная становится «игрой дня» в шапке, а её арт задаёт цвет всей страницы.
- **Синхронизация со Steam.** Каждый вставляет ссылку на свой профиль. Игры, которые есть хотя бы у двоих, сами попадают на полку, а те, в которые компания чаще играет, стоят выше.

### Сессии
- **Сессия в одно нажатие.** Бронирует общее окно и выбранную игру, остальные отвечают «Иду» или «Без меня».
- **Напоминание за час.** Бот пишет каждому лично: игра, время по его часам и кто идёт. Ответить можно кнопкой прямо в сообщении, не открывая приложение. Если общее окно есть, а сессию никто не начал, первое «Иду» в напоминании её создаёт.
- **Вечерний пинок.** Кто к 18:00 не отметил день, хотя остальные уже отметились, получает одно личное сообщение с кнопками «Отметить время» и «Сегодня NO».
- **Сводка в Discord.** Одно сообщение на день. Оно создаётся утром и обновляется после каждого изменения.

### Итоги
- **Итоги месяца:** сколько было сессий и игра месяца.
- **Лучший день недели:** когда за последние 8 недель вместе свободно больше всего народу и с какого часа обычно.

### Детали
- **Вход только через Telegram.** Приложение пускает только участников группы компании, без паролей и приглашений. Ник и аватарку можно поменять в профиле.
- **Всё обновляется вживую.** Кто-то отметил время, и у остальных шкала, неделя и шапка меняются сразу.
- **Экран загрузки.** Восемь постановок «сбора пати» из аватарок компании.
- **Родное поведение в Telegram.** Системная кнопка «Назад», вибрация на нажатиях, цвета шапки под тему.
- **Свой язык.** Подписи для тех, кто молчит или не может, подбираются случайно и меняются каждый день.

## Как устроено

```
Telegram ──initData──▶ /api/tg/auth ──▶ Supabase Auth (сессия)
   ▲                                          │
   │ напоминания, кнопки                     ▼
Бот ◀── /api/tg/remind ◀── pg_cron       Postgres + RLS ──realtime──▶ все открытые приложения
   └──▶ /api/tg/webhook (ответы)             ▲
                                              │
Steam Web API ──▶ ежедневная синхронизация ───┘──▶ Discord webhook (сводка дня)
```

| Слой | Что используется |
|---|---|
| Интерфейс | Next.js 16 (App Router, Server Actions), React 19, Tailwind CSS 4 |
| Данные | Supabase: Postgres с RLS, Realtime, Storage для аватарок и артов |
| Вход | Подпись `initData` мини-приложения (HMAC от токена бота) и проверка членства в группе |
| Фон | `pg_cron` + `pg_net` каждые 10 минут (напоминания), Vercel Cron раз в сутки (Discord, Steam) |
| Внешние API | Telegram Bot API, Steam Store и Steam Web API, Discord webhooks |

Всё работает на бесплатных тарифах Vercel и Supabase.

## Структура

```
src/
  app/            страницы, Server Actions и API (tg/auth, tg/remind, tg/webhook, cron, steam)
  components/     главная, день и шкала, сессии, заставка, Telegram-обвязка
  lib/            время и часовые пояса, поиск общего окна, Steam, Telegram, Discord, фразы
supabase/         миграции по порядку: schema.sql → 002 … 008
```

<details>
<summary><b>Своя копия</b></summary>

1. Создай проект в Supabase и по порядку запусти файлы из `supabase/`. `005_reminders.sql` — это шаблон: впиши в него адрес сайта и `CRON_SECRET`.
2. Создай бота в [@BotFather](https://t.me/BotFather), сделай для него мини-приложение (`/newapp`) и добавь бота в группу компании.
3. Скопируй `.env.example` в `.env.local` и заполни: ключи Supabase, токен бота, ID группы, ссылку на мини-приложение, адрес сайта, `CRON_SECRET`, `CREW_TIMEZONE`. По желанию добавь `STEAM_API_KEY` и `DISCORD_WEBHOOK_URL`.
4. Выложи на Vercel с теми же переменными.
5. Привяжи вебхук бота к `/api/tg/webhook`. Секрет выводится из токена: смотри `webhookSecret()` в `src/lib/telegram.ts`.

</details>
